# Portable API3 audit — 2026-10-23

The manifests opt into Portable API3 and require official Gen1Recomp **0.3.96 or later**. This audit read the official loader, UnifiedCallbacks, UnifiedWorld, UnifiedRecords, ModUI, native Gen3 options call site, and the API3 migration documentation. Mod versions and release artifacts are unchanged in this commit.

Public ownership now covers `ui.options.rows`, registered `content.screens`, `mod.ui.push`, ListMenu input/scroll/close, and launcher cleanup. Native options rows retain identity, order, callback arguments, and any future trailing arguments. Gen3 contributes one owned category instead of wrapping private `option_rows.build/group`. The registered category draws explicitly in the full 240×160 GBA canvas. The stock public ListMenu renders GB glyphs, absent from GBA profiles, so `Gen3OptionScreen` uses edition-native `frlg_font` and window art only for drawing. It preserves the public widget's input and stack lifecycle. No private overflow-menu wrapper is installed.

Options still persist through the current engine's owned save/loader option buckets and emit `mod.options_changed`; the public options facade has `define/get` and no setter. These narrow persistence and native-art extensions retain the declared `engine_internals` permission.

Native evidence on 2026-10-23 uses the unmodified official 0.3.96 engine and isolated profiles cloned from genuine imports. Every claimed edition passed the actual native options call site and a real wild battle through the public API3 world action: **Red, Blue, Yellow, Gold, Silver, Crystal, FireRed, LeafGreen, Ruby, Sapphire, Emerald**. Each run checked canonical detached party/move records, world cell/block metadata (16px cells; 32px GB blocks versus 16px GBA metatiles), empty-party refusal, actual battle command readiness and owner errors. Gen3 options additionally opened the registered group, changed/restored its first value, reached the final CANCEL row, and closed it. Screenshots were reviewed for native fonts, readable rows and command controls. All exercised `legacyReport(id)` results are empty. The committed JSONL records log hashes and source fingerprints, without ROM data, caches or captures.

These are standalone fixture-driven native runs, not a full gameplay, mobile-device or live multiplayer certification. Combined-mod release validation is coordinated separately.

Wilds resolves the live game through the documented lazy **`mod.game`**, because the API3 world facade has no `.game`. Encounter, follower, catching, configuration, rendering and shared-spawn paths use that live owner. Gen1/2 encounters call the validated scalar public `world:startWildBattle` action and normalize native Gen2 aliases (`FARFETCH_D`/`MR__MIME`). Gen3 converts native numeric species to canonical strings only at that public action boundary. Its narrow owned native descriptor extension preserves host PID/shiny identity through delayed battle startup; it does not bypass public refusal checks. All five native Gen3 battle fixtures exercised `spawn → encounter` and retained PID `4294967295` plus the forced shiny flag.

API3 party callbacks supply detached canonical records. Follower selection matches their diagnostic native identity to the live party, preserves existing persisted OT/DV fingerprints, distinguishes duplicate species, and rechecks live HP before selection. The official SDK `UnifiedRecords.mon` test covers both GB generations and stale callbacks. The native Gen2 icon renderer retains its instance/held-item behavior; Wilds no longer probes the unsupported Gen1 static draw facade on Gen2.

Live packaged-asset misses now remain public `mod:read`/asset-loader misses instead of retrying removed sandbox `io.open`/`loadfile` shims. Plain Lua fixtures without a public owner retain their filesystem fallback. No world-service coordinates or native movement bounds were changed. Existing native sprite/capture/presentation extensions remain under `engine_internals`; no public arbitrary native-actor draw replacement exists. The experimental AI dialogue option remains **OFF by default** in both schema and runtime defaults; no feature expansion or network-default change was made.

Validation: **113** local suites pass against official0.3.96 SDK paths, including canonical records, native identity, Gen2 party submenu, public options, sandbox asset access, config migrations, catching and behavior. All production Lua compiles and `git diff --check` passes. Five older broad suites remain non-green: generated sprite/color/water assets are absent in their fixture setup (`gen2_sprite_color`, `poke_followers_assets`, `true_size_water_height`); two engine-root modkit suites are not runnable from the standalone mod cwd (`overworld_wild_spawns`, `voxel_aggressive_compat`). These fixture limitations are not reported as passing or as native evidence. The official native Gen1/2 shared capture/storage suite passes after migrating its mock to `mod.game`.
